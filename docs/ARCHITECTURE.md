# HELIOS Architecture — Foundation Contract

## Non-negotiable system rules

1. Provider measurements are never fabricated.
2. Provider failures are explicit.
3. Premium endpoints are optional capabilities, not assumed dependencies.
4. All provider activity IDs are retainable as provenance.
5. Numerical/scientific modules will consume normalized HELIOS contracts, not raw vendor JSON.
6. LLMs will never own numerical environmental truth.
7. Every modelled intervention result will be distinguishable from observed FortyGuard data.
8. Spatial data is stored in PostGIS.
9. Public API contracts are versioned under `/api/v1`.
10. Tests accompany every intelligence engine.
